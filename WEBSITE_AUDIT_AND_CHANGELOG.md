# Hambare Geosurveys Website — Version 19

## Changes in this release

- Added explicit previous/next controls, item counters and progress dots to the mobile project-route, core-service and field-to-file carousels.
- Added gentle mobile auto-advance, which pauses during interaction and is disabled when reduced-motion preferences are enabled.
- Replaced the non-Nigerian field-survey photograph with a Hambare-branded representation of a Black Nigerian surveyor viewed from behind.
- Changed the mobile solution selector to a fully visible two-by-two grid.
- Changed deliverable tabs to a fully visible two-by-two mobile grid and added previous/next output controls with an item counter.
- Removed the horizontally hidden company-fact cards; all company facts are now visible in a vertical mobile layout.
- Rebuilt the form tutorial as separate landscape and portrait videos.
- Added large burned-in pointers and captions, an English captions track, responsive posters and a dedicated full-screen button.
- The website automatically selects the portrait tutorial on phones and the landscape tutorial on larger screens.
- Updated the transcript and project-brief guidance.

## Content safeguards

The new field image is labelled as a Hambare-branded representation and is not presented as evidence of a completed client project. No clients, project statistics or unverified registrations were added.
