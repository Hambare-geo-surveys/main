# Hambare Geosurveys Website — Version 19

Open `index.html` through a local web server or deploy the folder to static hosting.

For a single-file demonstration, open:

`Hambare_Geosurveys_Interactive_Preview.html`

That preview embeds the website styling, JavaScript, imagery, technical illustrations and both tutorial-video versions.

## Primary files

- `index.html` — production homepage
- `assets/styles.css` — responsive styling
- `assets/app.js` — navigation, carousels, deliverables and project-brief logic
- `assets/media/hambare-form-guide-landscape.mp4` — desktop tutorial
- `assets/media/hambare-form-guide-portrait.mp4` — mobile tutorial
- `assets/media/hambare-form-guide.en.vtt` — English captions
- `assets/media/hambare-form-guide-transcript.txt` — transcript

## Deployment

The website is static and can be deployed to GitHub Pages, Cloudflare Pages, Netlify or normal shared hosting. Replace representative imagery only with authorised Hambare project photographs.
